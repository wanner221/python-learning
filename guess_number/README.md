# Guess Number

## 项目简介

一个使用 Python 编写的命令行猜数字游戏。

这是我学习 Python 初期完成的第一个完整项目，用来练习基础语法、函数、异常处理和简单的程序设计。

游戏会随机生成一个目标数字，玩家在限定次数内猜测，程序每次提示“偏大 / 偏小”和剩余机会；游戏提供三档难度并按表现计分，获胜成绩会进入本次运行的排行榜。

## 功能

- 输入玩家名称，多局游戏共用
- 三档难度，数字范围、猜测次数和基础分各不相同
- 使用 `random.randint()` 生成随机目标数字
- 限制猜测次数，次数用完即本局失败
- 非数字输入会被捕获并提示重新输入，程序不会崩溃
- 每次猜测后根据结果提示偏大、偏小或猜中，并在未猜中时显示剩余次数
- 按难度基础分和猜测次数计分，失败得 0 分
- 获胜玩家进入排行榜，按分数从高到低排序
- 每局结束后可选择重新开始或退出

## 游戏难度

| 难度 | 选项 | 数字范围 | 最大猜测次数 | 基础分 |
| --- | --- | --- | ---: | ---: |
| 简单 | 1 | 1 ~ 50 | 10 | 100 |
| 普通 | 2 | 1 ~ 100 | 7 | 200 |
| 困难 | 3 | 1 ~ 1000 | 5 | 300 |

## 使用的技术

- Python 3，仅使用标准库
- `random.randint()` 生成随机目标数字
- 函数定义、参数传递与 `return`（含元组形式的多返回值解包）
- `if / elif / else` 条件判断
- `while` 循环与 `for` 循环（`enumerate()` 遍历排行榜）
- `try / except ValueError` 处理非法输入
- 列表与 `sorted()`、`lambda` 排序
- 模块化（`import` 同目录模块）与 `if __name__ == "__main__"` 入口判断

## 核心设计

- **模块化**：游戏逻辑封装在 `game.py` 的各个函数中，`main.py` 只负责主流程调度，通过 `from game import *` 复用。
- **函数职责划分**：随机数生成、难度选择、输入验证、猜测判断、分数计算、结果展示、重开询问各自由独立函数完成。
- **参数与返回值**：函数之间通过参数传入数据、通过 `return` 回传结果；例如 `choose_level()` 一次返回 `(数字范围, 次数, 基础分)`，`check_number()` 返回 `(是否猜中, 猜测次数)`，调用处直接解包。
- **输入与异常处理**：`get_level_choice()` 和 `get_number_input()` 均用 `while` 循环配合 `try / except ValueError` 处理非数字输入，不会中断程序；其中 `get_level_choice()` 还会校验难度选项必须为 1~3，而 `get_number_input()` 目前只校验输入是否为整数，暂未进行猜测数字的范围校验。
- **计分逻辑**：猜中的那一次不扣分，每猜错一次扣 10 分，最低 0 分；失败直接得 0 分。
- **排行榜**：用内存中的列表保存 `[玩家名称, 分数]`，只有获胜才上榜，每局结束用 `sorted()` 按分数降序排列后输出；程序退出后排行榜不保留。
